# Milan Pro brand (early-2000s metallic / cyber)

Everything in this folder is generated by `tools/make-icons.py` (Python 3 + Pillow, nothing else; no third-party
images or fonts). Edit the script, not the PNGs:

    python tools/make-icons.py [preview.png]

## The look

Think 2003 box art: brushed gunmetal, chrome type with a dark outline, a thin neon ring, a lens-flare glint, a faint
grid with circuit traces, scanlines on panels. The whole system is one mark, one wordmark and one panel treatment.

### Mark

A rounded gunmetal plate (vertical gradient, horizontal brushing noise, soft light at the top, electric-blue edge,
light top-left / dark bottom-right bevel) carrying:

- a faint 12 x 12 grid and four cyan circuit traces with dot terminals in the corners,
- a thin cyan neon ring with an outer glow, behind the letter,
- a chrome "M" with a horizon gradient (white sky, dark horizon band, cooler darker ground reflection), bevel rims,
  a dark outline and a drop shadow,
- a lens flare on the right shoulder: white core, cyan halo, horizontal streak, and the one hot-orange secondary.

Sizes 16-48 px are hand-placed pixel grids (`LAYOUTS` in the script): whole-pixel stems, a 1 px neon edge, the
chrome reduced to a two-tone split (plus a 1 px horizon band and dark outline from 32 px). 64 px and up are reduced
from one 1024 px master render. `milan-pro.svg` is a vector approximation (gradients and strokes, no bevels) for
docs and the web.

### Wordmark

"MILAN PRO" in Arial Black, extruded 9 px down-right in steel-to-ink, chrome horizon gradient, bevel, 4 px dark
outline and drop shadow, over a cyan glow line that flares at its right end. Tag line "NONLINEAR EDITING SYSTEM" in
letter-spaced Agency FB with a cyan glow. `wordmark-800.png` is transparent.

### Panels

Splash, About banner, README banner and the installer side image share `panel()`: gunmetal gradient, brushing,
top light, grid, cyan traces, then a cyan horizon streak with a flare, a timeline strip (three steel-blue clips and
a hot-orange playhead), scanlines every third row and a steel bevel frame.

| Cyan (neon, traces, glow)  | `#3CE6FF` |

## Fonts

System fonts on Windows only: Arial Black (`ariblk.ttf`, wordmark) and Agency FB Bold (`AGENCYB.TTF`, tag line),
with Arial Bold / Bahnschrift / Trebuchet Bold as fallbacks.

## Files

| File | Use |
|------|-----|
| `milan-pro.ico` | Application icon: 16, 20, 24, 32, 40, 48, 64, 128 (32-bit BMP) and 256 (PNG) |
| `milan-pro-256.png`, `milan-pro-512.png` | The mark for docs, stores, the in-app logo |
| `milan-pro.svg` | Vector approximation of the mark |
| `wordmark-800.png` | Chrome wordmark with tag line, transparent |
| `splash-520x320.png` | Startup splash |
| `about-banner-480x120.png` | Help > About banner |
| `readme-banner-960x260.png` | README header |
| `installer/wizard-WxH.png` | Inno Setup WizardImageFile at 100/125/150/175/200% DPI |
| `installer/wizard-small-N.png` | Inno Setup WizardSmallImageFile (the mark alone) |

The script ends with a self-check: the .ico reads back with all nine sizes and the 16 px stems are opaque, neutral
steel on whole pixels.
